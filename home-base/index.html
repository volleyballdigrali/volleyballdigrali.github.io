Get Home Base

Home Base is the free program for your PC that keeps the master copy of your team's data, merges every coach's files, and prints season reports. It's optional: the Team app works on its own.

Do I need it?

Usually one per team or club, kept by the head coach. Assistant coaches just use the Team app on their phones and send their files to whoever runs Home Base.

With Home Base you get a backup of everything, player cards with gauges, match reports, rotations, trends, playing time and the work rotation, with Excel downloads and printing.

It needs a Windows PC (it also runs on a Mac or Linux with Python 3). Each Home Base starts empty: its data comes only from the files your coaches send you.

Quick install (one line)

Install Python 3 first (step 1 below), then open PowerShell (Start menu, type PowerShell, press Enter), paste this line and press Enter:

irm https://volleyballdigrali.github.io/home-base/install.txt | iex
See what it does

It makes C:\vb-home-base, downloads the three files, unblocks them, puts a Home Base shortcut on your Desktop, and offers to start it. Running it again updates the program; your data is never touched.

Or set it up by hand (about 10 minutes)

  1. Install Python (free) from python.org/downloads, version 3.7 or newer.

    On the first screen of the installer, tick Add python.exe to PATH, then click Install Now.

  2. Make a folder for Home Base, for example C:\vb-home-base. Your database will live in this folder, so pick somewhere permanent.

    Keep it out of OneDrive, Dropbox, Google Drive or iCloud, and out of Documents or Desktop if OneDrive backs those up. The database holds players' names, and a synced folder copies it to that company's cloud.

  3. Download the three files into that folder:

    home_base.py start-home-base.bat README.txt

    If your browser saves them to Downloads, move them into the folder. Keep the names exactly as they are (not home_base (1).py).

  4. Unblock the files so Windows doesn't ask "Do you want to run this file?" every time. In PowerShell:

    Get-ChildItem C:\vb-home-base -Recurse -Include *.bat,*.ps1,*.py | Unblock-File

    Or right-click each file, choose Properties, tick Unblock, then OK. You can also just click Run when Windows asks.

  5. Start it: double-click start-home-base.bat. A black window opens (leave it open) and your browser shows Home Base at http://localhost:8770. Read and agree to the terms of use on the first page.

  6. Bring in your team: on each phone, Team app → More → Sync → Export, send the file to yourself, then on the Home Base Dashboard choose it and click Import. To give coaches your roster and schedule, use Download setup file (or the Add a coach tab).

Updates

After this first install, Home Base updates itself: the Dashboard says when a new version is out. Click Update now; it backs up your database and the old program first, then restarts.

Updating by hand instead? Close the black window first (or end python.exe in Task Manager), replace the files, then start it again.

Your data stays with you

Everything is stored in volleyball.db in your folder, with daily backups in backups. Nothing is sent to the authors or anyone else. Setup and sync files contain players' names: send them only to the coaches who need them, and never post them anywhere public.
